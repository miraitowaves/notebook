Q ( 2026-01-12 ): 推荐系统实验中常用的 HR@n 和 NDCG@n 有什么区别？

A:

1. **HR@n (命中率)**：只看“在不在”。只要正确答案在前 $n$ 名里，就计为 1 分，不在则 0 分
2. **NDCG@n (排名增益)**：不仅看“在不在”，还看“准不准”。正确答案排在第 1 名的分数比排在第 $n$ 名的分数高，对**排名顺序 (Ranking order)** 更敏感

Q ( 2026-01-12 ): 什么是 留一法 (Leave-one-out) 评估？

A:

- **做法**：把用户行为序列的最后一个物品藏起来作为测试集，前面的物品作为训练集
- **目的**：模拟真实场景——根据用户过去所有的行为，预测他“下一时刻”最想买什么

Q ( 2026-01-12 ): 为什么实验要跑 5 次随机种子取平均值？

A:

- 为了保证**稳健性 (Robustness)**。深度学习模型对初始化参数很敏感，跑多次取平均可以证明算法的提升是真实的，而不是靠运气碰上的

**Q** ( 2026-01-12 ): 如何总结 **LLMRG** 的实验表现？ **A**:

1. **强普适性**：它不是一个独立模型，而是一个**增强框架**，能让 BERT4Rec、DuoRec 等现有模型变得更强。
2. **推理胜过直觉**：消融实验证明，构建“推理图”远比直接向 LLM 询问推荐结果更有效。
3. **克服稀疏性**：在行为数据较少的数据集上，利用 GPT-4 提取的外部属性关联能显著提升命中率 (HR)。

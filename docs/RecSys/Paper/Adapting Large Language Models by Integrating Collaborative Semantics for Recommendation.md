- ID 生成离散的具备语义的索引，同时进行均匀语义映射，消除重复 ID
- 用一些微调任务，建立语言空间和协同空间的映射关系
  理解 Language Space ＆ Collaborative Sapce
  Language Space：物品的语义空间，在名字、内容等一系列物品属性上相似的物品相近
  Collaborative Space：建立在用户与物品的交互历史上，例如购买烟和购买酒，它们在这个空间上相似，是因为购买烟/酒的用户很多也同时购买了酒/烟
